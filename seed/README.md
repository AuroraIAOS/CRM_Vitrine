# seed/ — CRM Vitrine

Dados fictícios para popular ambiente de demonstração (o CRM Vitrine é literalmente uma vitrine — precisa parecer usado). Gerado na **Subetapa 02.4** do Claude CODE.

## Regra

Nenhum dado real de cliente entra aqui, nunca. Nomes, telefones, e-mails e documentos são todos fictícios, gerados propositalmente para demonstração.

## Cobertura esperada (v01)

Pelo menos: 1 conta de demonstração; pessoas em cada papel (lead, cliente, funcionário, fornecedor); 1 funil de vendas com oportunidades em etapas diferentes; conversas de exemplo em `aba_messaging`; 1 contrato/fatura em `aba_finance`; 1 prontuário fictício em `aba_health` (com consentimento fictício correspondente).
