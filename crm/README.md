# crm/ — CRM Vitrine

- `crm/src/` — aplicação Vite+React+TS, seguindo a mesma estrutura de pastas do CRM Sindcom (`src/features/`, `src/components/`, etc.).
- `crm/public/` — assets estáticos + manifest PWA.
- `crm/package.json`, `crm/vite.config.ts` — gerados na Subetapa 01.1.
